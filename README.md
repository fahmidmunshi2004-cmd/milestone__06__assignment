# DigiTools

DigiTools is a responsive digital tools buying website built for the A-6 assignment. It includes a Figma-inspired landing page, reusable product cards, cart management, and toast feedback for add/remove/checkout actions.

## Technology Used

- React.js
- Tailwind CSS
- DaisyUI-ready component structure
- JavaScript (ES6+)
- React Toastify
- JSON-style in-component product data

## Features

- Responsive hero, stats, products, steps, pricing, CTA, and footer sections
- Product and cart toggle with navbar cart count
- Add to cart, remove item, and proceed to checkout behavior with toast messages
